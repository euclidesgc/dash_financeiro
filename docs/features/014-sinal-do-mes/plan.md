# PLAN 014 — sinal do mês

Branch: `feature/014-sinal-do-mes`

Decisões registradas aqui (a SPEC deixou ao plano, ou o plano encontrou ao ler o código; escolhido o mais simples):

- **Os três handlers MSW novos e o `resetPlan()` em `src/testing/setup.ts` entram na fase 1, com o backend**, para a fase 2 nascer com o contrato simulado igual ao real (modelo dos planos 012 e 013). A fase 1 é só Python mais `src/testing/mocks/handlers.ts` e `src/testing/setup.ts`; `pnpm typecheck` continua verde porque os handlers respondem `HttpResponse.json` sem tipo e `handlers.ts` já importa `CategorySignal`.
- **O mock de `month-signal` soma `filterExpenses(url)`** como a SPEC pede, embora o endpoint real só aceite `from`/`to`: o cliente nunca manda `account_id` nem `q` para essa rota, então os dois coincidem no que a tela exercita.
- **`store.put` reaproveita a leitura prévia de `valid_until` que `write` já faz** — a consulta `SELECT valid_until FROM plan_facts WHERE name = ?` vira uma função privada `_valid_until(conn, name)` usada pelas duas, para a regra "preserva a validade" ter um único dono.
- **`test_route_guard.py::test_every_registered_route_requires_session` já cobre as rotas novas** sem alteração: o guard é global e o teste percorre as rotas registradas.
- **O teste de `limit-cents` muda só de caminho e de import** (`'../cents'`); os cinco nomes ficam iguais. Nenhum teste existente do front muda de nome.
- **O teste e2e novo entra em `e2e/expenses.spec.ts`** (o arquivo já está em `mode: 'serial'` e `playwright.config.ts` tem `workers: 1`), como um `test(` a mais, depois de `shows the signal of each category against its limit only in a whole month and leaves the base as it found it` e antes de `goes back to the balances page`; ele deixa a base como encontrou apagando o teto no fim. O login segue o padrão do arquivo (`/app/login`, `Login`, `Senha`, "Entrar"). Os números batem com `tests/data/e2e_transactions.json`: 2026-08 tem -60,00 (`e2e-t-6`) e -45,00 (`e2e-t-5`) = R$ 105,00.
- **`docs/roadmap.md`**: a linha `| 014 | \`sinal-do-mes\` |` passa de `in-progress` a `in-review` na fase 2, ao abrir o PR.
